PRODIGY_ML_01
House Price Prediction using Linear Regression
This project is done as part of Prodigy InfoTech Machine Learning Internship (Task 01).

In this task, I created a simple Linear Regression model in Python to predict house prices.
The prediction is based on:
- House area (square feet)
- Number of bedrooms
- Number of bathrooms

Dataset:
House Prices – Advanced Regression Techniques  
https://www.kaggle.com/c/house-prices-advanced-regression-techniques/data

The dataset is used only for training the model and is not uploaded to this repository.
Tools used:
- Python
- Pandas
- NumPy
- Scikit-learn

How to run:
1. Install required libraries
2. Run the Python file
   python prodigy-ml-01.py
The program takes user input and predicts the house price.
